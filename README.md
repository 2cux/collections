# 曹波个人网站

沿用 Vite、GSAP 和 Three.js。原 hello!、弹球、二维矩形和 I'm caobo 时间轴保留；欢迎到螺旋页由独立时间轴控制。没有音频、真实作品或菜单按钮。

## 运行

```sh
npm run dev
npm run build
```

## 调整位置

- `src/projects.js`：真实作品数组 `projects`，当前为空。每项可按 `{ cover, title, link, aspect, size, tiltX, tiltY, tiltZ, radialOffset }` 填入；后 6 个字段均有安全默认值，且空数组会使用固定的占位视觉配置。
- `src/gallery.js`：`SPIRAL_LAYOUT` 集中配置桌面/手机螺旋半径、每圈螺距、角间距、基础卡片宽度、槽位数量、相机距离、输入速度、阻尼和像素比上限。移动端使用独立相机距离、目标占屏比和上下限；卡片使用共享 UV 平面与轻度横向弯曲，再由项目数据控制比例、尺寸和微小姿态偏移；滚轮、拖动和键盘输入结束约 150ms 后，会向最近标准槽位柔和磁吸。焦点视觉使用 9 次以内的 3×3 卡片空间采样，并按焦点、速度和设备能力分级；桌面精确指针支持真实项目 hover，网格只做几像素级视差。
- `src/transition.js`：`TRANSITION_TIMING` 配置转场节奏，总时长默认 1.55 秒。文字、球体、网格、舞台与顶部标识共用一个新时间轴。
- `src/styles.css`：末尾 gallery 样式控制网格、顶部边距、标识尺寸和静态降级槽位。
- `src/intro.js`：原开场参数与个人文案保持在 `INTRO_*` 中。旧开场停在 final，新转场只由 enter 触发。

笑脸复用同一 DOM 节点和 canvas，通过占位元素保持欢迎布局；以实际 DOM 矩形计算飞行起终点，并在 resize 后更新终点。画廊提前初始化，不等点击后加载。滚轮、方向键和手机纵向拖动采用有限进度，输入期间自由滚动，结束后阻尼收敛到最近槽位；卡片沿周期化螺旋槽位回收，正反向跨越循环边界保持连续。焦点由归一化螺旋角度、相机距离、屏幕中心投影距离和当前速度共同计算，并统一驱动缩放、亮度、透明度与轻微纹理模糊；高速时仅对非主卡片增加克制的切线方向采样。空白槽位没有可点击链接，真实项目才会进入 hover/click 预留路径。静止时按需渲染，隐藏标签页暂停，卸载清理监听器与 GPU 资源；首批帧耗时过高时会从 high 渐进降到 medium/low，避免频繁质量抖动。

## 检查入口

- `/?replay=1`：重播完整开场。
- `/?intro-state=hello`、`name`、`final`：查看开场关键状态。
- `/?replay=1&debug=1`：开发环境显示 replay intro，用于检查进入后重播。
- `/?intro-state=final&no-webgl=1`：模拟无 WebGL，显示静态灰色卡片及 CSS 笑脸。
- `/?intro-state=final&reduced-motion=1`：开发环境模拟减少动态效果，进入使用短淡入。

## 本轮验证

生产构建通过（Vite 提示包含 Three.js 的主包超过 500 kB）。浏览器检查了 WebGL 画廊启动、键盘移动、滚轮、指针拖动释放后的磁吸、spiral/list 往返、无 WebGL fallback 和 reduced-motion 分支；新会话控制台无错误或警告。使用显式 viewport 检查了 360×800、375×812、390×844、430×932、768×1024、844×390、1366×768、1440×900、1920×1080、2560×1440；各尺寸画布均正确铺满，顶部控件和底部信息保持在视口内，移动端进入独立相机布局。真实手机触摸、系统动态偏好切换、真实 GPU 上下文丢失、温度/电量表现和带真实 `link` 项目的 hover/click 仍需设备与实际项目数据复核。转场方案按本次要求设计，不声称是参考站的精确动画。
